Questions

Bon à savoir

Faut-il un compte ?

Non. Rien à créer, rien à connecter.

Où sont mes données ?

Sur ton PC, dans ton dossier utilisateur (%APPDATA%\Vectorem). Elles ne partent pas sur un serveur. L'app vérifie au plus une fois par jour s'il existe une nouvelle version ; tu peux couper cette vérification dans les Réglages.

Faut-il l'app Android ?

Non, Vectorem pour Windows marche seul. Avec le téléphone associé, tu gagnes la synchronisation, l'envoi de fichiers et la télécommande.

Pourquoi Windows affiche un avertissement ?

Parce que l'installateur de l'aperçu n'est pas encore signé par un certificat. C'est prévu avant la version publique.

Et sur Mac ou Linux ?

Pas pour l'instant. Windows d'abord.

Comment désinstaller ?

Paramètres Windows › Applications › Vectorem. Tes données restent dans %APPDATA%\Vectorem tant que tu ne supprimes pas ce dossier.
